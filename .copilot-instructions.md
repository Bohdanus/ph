# Copilot Instructions

## Code Quality

- **Correctness first.** Prioritize code quality over speed. Verify changes work.
- **No token-expensive loops.** Always ask before deep iteration/looping patterns that consume tokens.
- **Surgical changes.** Make precise edits. Don't refactor unrelated code.

## Testing

- Unit tests are low priority. Focus on core functionality.
- Run existing tests to ensure no regressions.
- **Never open a browser window.** `npm run test:e2e` is headless; do not pass
  `--headed`, `--ui` or `--debug`, do not run `show-report` / `show-trace` / `codegen`,
  and do not set `PLAYWRIGHT_ALLOW_HEADED`. A live window takes over the operator's
  screen and their input reaches the page as real test input. If a visible browser is
  genuinely needed, ask them to run `npm run test:e2e:headed`. See `AGENTS.md`.

## Documentation

- **Every sub-feature needs a spec file.**
- Spec must be brief and focused on main functional/business requirements only.
- Path: `[feature-dir]/SPEC.md`

## General

- Keep solutions small and focused.
- Ask for confirmation on ambiguous decisions.
- Validate changes before considering task complete.
