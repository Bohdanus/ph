All conflict resolution stays in the candidate, never in the damaged root checkout. The second synchronization had five conflicts:

- `scripts/lib/free-model-kilo.mjs` keeps upstream free-model profile caps and the Nemotron reasoning variant, plus the local descendant cleanup behavior. Provider quota events now take precedence over a concurrent stdin `EPIPE`; a regression test verifies the sanitized 429 result.
- `scripts/lib/windows-process-tree.mjs` and `scripts/__tests__/free-model-kilo.test.mjs` retain taskkill-only Windows termination, the PID-reuse guard, and both branches' lifecycle tests. Failed `taskkill` does not fall back to `ParentProcessId` enumeration. The pool treats a termination failure as a stop for the Kilo source in that run.
- `scripts/__tests__/test-write-boundaries.test.mjs` combines the upstream `spawnSync` cleanup assertion with the local filesystem write counts and lifecycle scope.
- `src/tools/__tests__/blur.test.ts` retains the local missing-bitmap guard and upstream Canvas filter behavior coverage.

The Windows process-tree helper no longer falls back from failed `taskkill` to WMI `ParentProcessId` enumeration and `Stop-Process`. Microsoft's `Win32_Process` documentation warns that a parent PID can be reused; PID enumeration could therefore kill an unrelated process. The helper now fails closed when `taskkill` fails. On Windows the Kilo runner checks Node's observed child exit state before invoking tree termination or signaling the child; on POSIX it signals the isolated process group so descendants remain reachable if the leader exits. References: [Microsoft Win32_Process](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-process) and [Node.js child_process](https://nodejs.org/api/child_process.html).

The stale-merge recovery content pin now hashes regular files in bounded 64 KiB chunks rather than reading a potentially large PSD into memory. Its regression test changes the last byte of a multi-chunk untracked asset after preflight and confirms recovery preserves both the changed asset and marker. The test fixture disables `core.autocrlf` for deterministic hashes, and its POSIX-only shell race case is skipped on Windows.

`TEST-FLAKES.md` section 12 was renamed to a historical report in the incoming tree, not dropped. It preserves the viewport-drawing and raw-CDP capture history while documenting the Playwright screenshot API and active assertion. In `e2e/OPEN_PROBLEMS.md`, four resolved reports were removed only after checking the current implementation/tests: page-vs-CDP clip coordinates, `Page.captureScreenshot` viewport drift, letterbox backdrop counted as ink, and the alpha-sample wording.
