The prepared merge combines local `main` with the fetched `origin/main`. The two textual conflicts were resolved in the candidate, never in the damaged root checkout:

- `scripts/__tests__/free-model-kilo.test.mjs` retains the incoming canonical `xingchen-agi/xing4.0-29b-a4b:free` fixture and malformed-JSONL coverage while retaining the local exact Nemotron approval/policy checks, invalid-cost timeout coverage, and process-tree cleanup coverage. - `scripts/__tests__/test-write-boundaries.test.mjs` retains the incoming E2E timeout-contract and expanded fixture/write counts together with local process-lifecycle scopes and assertions. Its scanner test is included in the repository test gates.

The current Windows process-tree helper no longer falls back from failed `taskkill` to WMI `ParentProcessId` enumeration and `Stop-Process`. Microsoft's `Win32_Process` documentation warns that a parent PID can be reused; PID enumeration could therefore kill an unrelated process. The helper now fails closed when `taskkill` fails, and the Kilo runner checks Node's observed child exit state before invoking tree termination or signaling the child. This matches Node's warning that signaling a process after it exits may target a reused PID. References: [Microsoft Win32_Process](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-process) and [Node.js child_process](https://nodejs.org/api/child_process.html).

`TEST-FLAKES.md` section 12 was renamed to a historical report in the incoming tree, not dropped. It preserves the viewport-drawing and raw-CDP capture history while documenting the Playwright screenshot API and active assertion. In `e2e/OPEN_PROBLEMS.md`, four resolved reports were removed only after checking the current implementation/tests: page-vs-CDP clip coordinates, `Page.captureScreenshot` viewport drift, letterbox backdrop counted as ink, and the alpha-sample wording. Current screenshot and pixel-mask coverage is recorded in the E2E tests; the earlier screenshot API change is in commit `d0da6c3b`, and the spatial backdrop mask is in `b6e47f44`.
